Exchange-gate control for silicon spin qubits

Two electrons in a silicon double dot interact through an exchange coupling J that is set by a gate voltage. This page shapes J(t) to produce √SWAP, SWAP and CZ gates, then asks how those pulses hold up against charge noise, nuclear-spin fluctuations, relaxation and valley leakage. The calculations run here in the browser and follow the Python package line for line.

Method
  • Hamiltonian. H/h = (J/4)(XX + YY + ZZ) + (ΔBz/2)(Z₁ − Z₂) in the frame rotating at the mean Zeeman frequency. Each time slice is exponentiated in closed form: |↑↑⟩ and |↓↓⟩ acquire e−iφJ/4 and the {|↑↓⟩, |↓↑⟩} block is a 2×2 rotation, with φ = 2π·10⁻³·dt for J in MHz and dt in ns.
  • Pulse. J(t) = clip(Σ aₖ sin(kπt/T) + bₖ(1 − cos 2kπt/T), 0, Jmax) on slice midpoints, as in the Python SmoothFourierPulse.
  • Optimiser. BFGS on 1 − F plus a small slew-rate penalty, from three starting areas (a quarter, a half and three quarters of a full exchange cycle). It runs in a Web Worker so the page stays responsive. The Python version uses JAX gradients and L-BFGS-B on the same loss.
  • Noise. Charge noise δε(t) is a sum of 48 log-spaced tones with 1/f amplitudes and random phases, entering as J → J·exp(δε/ε₀). The nuclear field is a Gaussian shift of ΔBz, redrawn for each realisation.
  • Decoherence. Relaxation (σ⁻) and dephasing (σz/√2) on each electron with γ₁ = 1/T₁ and γφ = 1/T₂* − 1/(2T₁). The 16×16 Liouvillian is exponentiated for each distinct J, and the result is the process fidelity Tr(SU†S)/16.
  • Pulse shapes. Square, cosine (Hann), Tukey and Blackman windows are scaled to area 500 MHz·ns. The conditional phase is then exactly π, because the {|↑↓⟩, |↓↑⟩} block is a phase times an SU(2) matrix. The plotted error is the average-gate infidelity to CZ after the optimal single-qubit Z corrections.
  • Benchmarking. The 11 520 two-qubit Cliffords are generated by closure of {H⊗I, I⊗H, S⊗I, I⊗S, CNOT}, and density matrices are evolved with amplitude and phase damping after every layer. The interleaved error is r = ¾(1 − pint/pref).
  • Valley leakage. An 8×8 spin ⊗ valley model with Ev/2·τz and Δsoc(Z₁ − Z₂)⊗τx, starting from the singlet in the lower valley.
  • Limits. Exchange is a single control axis, so averaging over an error ensemble buys little robustness against amplitude errors. Charge noise is treated as quasi-static within each gate.
