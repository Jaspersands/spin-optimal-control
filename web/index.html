Differentiable optimal control for silicon spin exchange gates

Everything on this page is computed in your browser by a compact JavaScript port of the Python package: the two-electron Hamiltonian is propagated exactly, the pulse is optimised by BFGS on a band-limited Fourier basis, noise is sampled from a 1/f spectrum, decoherence is solved with a 16×16 Liouvillian, and randomized benchmarking draws from the full 11 520-element two-qubit Clifford group.

How this page computes its numbers
  • Hamiltonian. H/h = (J/4)(XX+YY+ZZ) + (ΔBz/2)(Z₁−Z₂) in the rotating frame. Each time slice is exponentiated in closed form: |T₊⟩,|T₋⟩ pick up e−iφJ/4 and the {|↑↓⟩,|↓↑⟩} block is a 2×2 rotation, with φ = 2π·10⁻³·dt.
  • Pulse. J(t) = clip(Σ aₖ sin(kπt/T) + bₖ(1−cos 2kπt/T), 0, Jmax) on slice midpoints — identical to the Python SmoothFourierPulse.
  • Optimiser. BFGS with Armijo backtracking on 1 − F + λ·mean(dJ/dt)², central-difference gradients, three area-sized starts (0.25/0.5/0.75 cycles). Python uses JAX autodiff + L-BFGS-B; the loss is the same.
  • Virtual-Z. Four extra parameters Rz(a)⊗Rz(b) before and Rz(c)⊗Rz(d) after the gate are optimised jointly — free frame updates on hardware.
  • Noise. δε(t) is synthesised from 48 log-spaced tones with 1/f amplitudes and random phases, normalised to the chosen RMS; J → J·exp(δε/ε₀). Overhauser shifts are Gaussian per trial.
  • Lindblad. σ⁻ and σz/√2 jump operators on each electron with γ₁ = 1/T₁, γφ = 1/T₂* − 1/(2T₁); the 16×16 Liouvillian is exponentiated per distinct J value and the process fidelity is Tr(SU†SE)/16.
  • RB. The Clifford group is generated on first use by breadth-first closure of {H⊗I, I⊗H, S⊗I, I⊗S, CNOT} modulo phase (11 520 elements). Density-matrix simulation with amplitude and phase damping per gate; interleaved error r = ¾(1 − pint/pref).
  • Valley. 8×8 spin ⊗ effective-valley Hamiltonian with Ev/2·τz and Δsoc·(Z₁−Z₂)⊗τx, exponentiated by scaling-and-squaring; leakage is the population in the upper valley starting from the singlet.
  • What is simplified. Single-axis exchange control cannot cancel amplitude errors, so "robust" gains are modest by physics, not by implementation. Charge noise is quasi-static within a shot.
